# E-commerce Website

A responsive business-style landing page built with HTML and CSS. The project combines a hero section, feature content, service plans, and a contact area into a single responsive frontend layout.

## Tech Stack

- HTML5
- CSS3
- Font Awesome
- Responsive Web Design

## Highlights

- Hero section with call to action
- Feature and planning sections
- Responsive content layout
- Contact and subscription area
- Icon-based UI elements

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mdjihad-dev/E-commerce-website.git
cd E-commerce-website
```

## Project Focus

This project was built to practice page structure, responsive CSS, visual hierarchy, and turning a provided design into a complete frontend page.
